# Mathematical contract

This document fixes the signs, dimensions, approximation model, and discrete
implementation used by v0.1.0. It distinguishes the equations verified in the
source material from this project's deliberate 3D RBF specialization.

## Scope and meaning of model-free

The controlled plant is an unknown translational Cartesian system

\[
M_C(q)\ddot x+C_C(q,\dot q)\dot x+F_C(\dot q)+G_C(q)
=f_c+K_h w_{ext}, \qquad x\in\mathbb R^3.
\]

The controller does **not** read or evaluate \(M_C,C_C,F_C,G_C\). That is the
only meaning of *model-free* here. A robot deployment still needs measured or
estimated joint state, forward kinematics, a Jacobian, Cartesian pose/twist,
frame transforms, and a robot-specific command mapping. v0.1.0 provides an
adapter interface but no hardware adapter.

The release implements translation only. It does not implement or claim a
validated 6D orientation controller.

## Impedance reference model

The prescribed response is

\[
M_m\ddot x_m+D_m\dot x_m+K_mx_m=K_hw_{ext}+f_a,
\]

with the full moving-reference auxiliary input

\[
f_a=M_m\ddot x_d+D_m\dot x_d+K_mx_d.
\]

For a fixed point, \(\dot x_d=\ddot x_d=0\), so this naturally reduces to
\(f_a=K_mx_d\). The external wrench sample used here is the same sample used
by the controller and simulated plant during that step.

The model-following signs are fixed as

\[
e_m=x_m-x,\qquad
\dot e_m=\dot x_m-\dot x,\qquad
r=\dot e_m+\Lambda e_m.
\]

These definitions must not be replaced with \(x-x_m\) without changing every
dependent control and adaptation sign.

## Lumped unknown dynamics

Substitution into the plant gives

\[
M_C\dot r=-C_Cr+G(z)-f_c-K_hw_{ext},
\]

where the paper defines

\[
G(z)=M_C(\ddot x_m+\Lambda\dot e_m)
 +C_C(\dot x_m+\Lambda e_m)+F_C+G_C.
\]

The paper's regressor contains \([q,\dot q,x_m,\dot x_m,\ddot x_m,e_m,
\dot e_m]\). The 3D deterministic demo has no joint-space robot model, so its
explicit v0.1 regressor is

\[
z=[x,\dot x,x_m,\dot x_m,\ddot x_m,e_m,\dot e_m]\in\mathbb R^{21}.
\]

The core accepts a fixed-size adapter-provided dynamics context in place of
\([x,\dot x]\). A future robot adapter may therefore supply \([q,\dot q]\),
but that adapter and its matching center set are not part of v0.1.0.

## RBF approximation contract

The manuscript and both reference implementations use a two-layer
sigmoid/tanh network, **not** an RBF network. v0.1.0 intentionally replaces
that network with a newly implemented fixed-basis Gaussian RBF model.

Each raw feature is scaled and clipped:

\[
\bar z_j=\operatorname{clip}(z_j/s_j,-c,c),\qquad c=3.
\]

For basis \(i\), center \(c_i\in\mathbb R^{21}\), and width \(b_i>0\),

\[
\phi_i(z)=\exp\!\left(-\frac{\lVert\bar z-c_i\rVert^2}{2b_i^2}\right).
\]

The deterministic default uses 31 centers generated by NumPy's seeded
generator (seed 7), uniformly in \([-0.75,0.75]^{21}\); center zero is forced
to the origin. All default widths are 2.5. Centers and widths remain fixed.

With \(\phi\in\mathbb R^{31}\) and
\(\hat W\in\mathbb R^{31\times3}\),

\[
\hat G(z)=\hat W^T\phi(z)\in\mathbb R^3.
\]

Weights start at exactly zero so reset and baseline runs are deterministic.

## Command and robust term

The paper writes

\[
f_c=\hat G+K_vr-\nu-K_hw_{ext},\qquad
\nu=-K_Z(\lVert\hat Z\rVert_F+Z_B)r.
\]

Therefore the effective robust contribution added to the command has a
positive sign. v0.1.0 writes that contribution directly as

\[
u_{rob}=(\lVert\hat W\rVert_F+b_r)K_rr,
\]

and computes

\[
\boxed{f_c^{raw}=\hat G+K_vr+u_{rob}-K_hw_{ext}}.
\]

The default \(b_r=1.5\) is a configurable robust bias, not a certified bound
on ideal neural weights. The command is then clipped per axis and, if needed,
scaled to a Euclidean norm limit. The applied command is

\[
f_c=\operatorname{saturate}(f_c^{raw}).
\]

Saturation is an explicit software safety layer and is not present in the
continuous proof from the manuscript.

## Adaptation law

Only the RBF output weights adapt:

\[
\dot{\hat W}=\gamma\left(\phi r^T
-\kappa\lVert r\rVert\hat W\right).
\]

The positive \(\phi r^T\) sign matches \(e_m=x_m-x\) and cancels the
corresponding ideal-weight cross term in the usual continuous Lyapunov
calculation. The leakage term is error-scaled; consequently zero error causes
no weight motion. With adaptation disabled, the update is a no-op.

The manuscript's extra input-layer update and activation-Jacobian correction
do not apply because the RBF centers are fixed. Its UUB theorem for a
two-adaptive-layer continuous network must not be presented as a proof for this
discrete, projected, saturated RBF implementation.

## External wrench placement and sign

For one coherent \(w_{ext,k}\):

1. the physical/demo plant receives \(+K_hw_{ext,k}\);
2. the impedance model receives \(+K_hw_{ext,k}\);
3. the NAC command contains \(-K_hw_{ext,k}\).

Under the ideal continuous assumptions these terms cancel from the inner-loop
model-following error dynamics while the impedance trajectory remains
compliant. A robot adapter must establish the wrench frame, point, direction,
units, filtering, delay, and gain before relying on this cancellation.
The bundled plant and controller each expose the same diagonal gain, with
identity defaults. Those two configuration values must remain equal.

## Discrete implementation

The manuscript does not specify an inner-loop numerical integrator. This
project therefore defines its own discrete contract.

For the impedance model, acceleration is evaluated from the old state and a
semi-implicit Euler step is used:

\[
\begin{aligned}
\ddot x_{m,k}&=M_m^{-1}(K_hw_{ext,k}+f_{a,k}
-D_m\dot x_{m,k}-K_mx_{m,k}),\\
\dot x_{m,k+1}&=\dot x_{m,k}+\Delta t\,\ddot x_{m,k},\\
x_{m,k+1}&=x_{m,k}+\Delta t\,\dot x_{m,k+1}.
\end{aligned}
\]

Weights use explicit Euler followed by Frobenius-norm projection:

\[
\hat W^*=\hat W_k+\Delta t\,\dot{\hat W}_k,
\qquad
\hat W_{k+1}=\Pi_{\lVert W\rVert_F\le W_{max}}(\hat W^*).
\]

The demo controller period is 0.002 s. Its unknown plant holds command and
external wrench for the controller interval and integrates four 0.0005 s
semi-implicit substeps. ROS message stamps advance by exactly the controller
period; wall-clock callbacks may miss deadlines without changing algorithmic
\(\Delta t\).

## Safety-state contract

The state machine is

```text
start -> running -> stopping -> stopped
             \-> fault
```

NaN/Inf, invalid time, time reversal, invalid \(\Delta t\), or watchdog expiry
latches `fault` and yields zero command. A fault requires explicit reset.
Reset restores the impedance state supplied by the caller, zero RBF weights,
watchdog history, saturation history, and the `start` state.

## Source comparison and chosen resolution

| Item | Manuscript | MuJoCo reference | Real wrapper | v0.1.0 choice |
|---|---|---|---|---|
| Controlled dimension | n-D position; 2D example | internal 6D approximation | internal 6D, sends translation only | 3D translation only |
| Error signs | \(x_m-x\), positive \(\Lambda\) | same | same | same |
| Moving feedforward | full M/D/K terms | full M/D/K terms | mode-dependent | always full for moving reference |
| NN | two-layer sigmoid | two-layer tanh | same imported structure | fixed Gaussian RBF |
| Adaptation | update input/output layers | explicit Euler input/output update | scaled update | output weights only, projection |
| Robust command | effective positive-r term | effective positive-r term | same | effective positive-r term |
| External wrench | plant/model `+`, command `-` | model/command match; modeled human path differs physically | measured frame/sign pipeline | one coherent 3D sample, `+ / + / -` |
| Integration | unspecified | semi-implicit model; explicit weights | wall-clock dt with clamp | fixed-step semi-implicit model; explicit weights |
| Reset | not a software contract | random NN initialization | does not reset NN weights | deterministic complete reset |

## Validity boundary

The unit and integration tests verify dimensions, signs, deterministic reset,
finite-value guards, numerical behavior, and repeatable tracking metrics. They
do not constitute a formal proof of the sampled-data saturated controller, a
hard real-time guarantee, or evidence of safe hardware operation.
