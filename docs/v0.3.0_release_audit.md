# v0.3.0 candidate release audit

## Status

**Candidate only — not released.** v0.1.0 remains the public release and
`CITATION.cff` remains unchanged. This feature branch must not be merged,
tagged, or released until the user reviews the committed animation and metrics and
explicitly authorizes publication.

## Candidate scope

The candidate adds a rotation-vector six-DoF impedance model, 42D two-layer
V/W neuro-adaptive controller, power-consistent analytical-force torque
mapping, full-dynamics unknown-payload benchmark, nominal/oracle comparisons,
and deterministic generated showcase artifacts. The earlier 3D Gaussian-RBF
core, APIs, demos, and artifacts remain available.

The adaptive controller does not read known robot/payload dynamics or MuJoCo
truth. It still requires measured joint state, FK/Jacobian kinematics, TCP pose
and twist. MuJoCo remains the sole owner of UR5e, articulated gripper, object,
collision, contact, and actuator dynamics.
