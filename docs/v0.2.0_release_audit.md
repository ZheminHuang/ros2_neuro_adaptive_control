# v0.2.0 candidate release audit

## Status

**Candidate only — not released.** v0.1.0 remains the public release and
`CITATION.cff` continues to identify v0.1.0. No v0.2.0 tag or release
should be created until the user has visually accepted both RViz launches and
every final gate below is complete.

## Candidate scope

The v0.2.0 candidate adds a single-owner MuJoCo 3.9.0 simulation of a UR5e,
the full articulated Robotiq 2F-85 public model, table, and free object. It
adds torque mapping, non-adaptive orientation hold, dynamic gripper action,
contact/raw-wrist telemetry, RViz visualization, deterministic tracking and
grasp runners, model provenance, and machine-readable evidence.

The NAC remains 3D translational. RViz is display-only. This candidate does
not include a real-robot adapter, validated 6D control, a manufacturer-
calibrated digital twin, hard-real-time execution, or a sim-to-real claim.

## Required visual acceptance

After building and sourcing the package, the user should inspect:

```bash
ros2 launch neuro_adaptive_control ur5e_mujoco_rviz.launch.py
ros2 launch neuro_adaptive_control ur5e_mujoco_grasp_demo.launch.py
```

Acceptance should confirm:

1. the UR5e and all visible 2F-85 links follow MuJoCo joint state without
   kinematic jumps or fabricated mimic motion;
2. desired green, impedance blue, and actual red paths/markers are distinct;
3. the orange NAC arrow and purple contact markers have plausible origins and
   directions;
4. the table and gold object align with contacts and the object is visibly
   grasped, lifted, held, lowered, and released;
5. RViz is observably a consumer: closing it does not change headless
   numerical results, and no RViz interaction commands the plant;
6. both finite launches stop cleanly without a fault diagnostic.

Record acceptance before changing this document or the changelog from
candidate wording to a dated release.
