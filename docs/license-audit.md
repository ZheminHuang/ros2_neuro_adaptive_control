# v0.1.0 license audit

Audit date: 2026-08-03.

## First-party material

- All Python, launch, configuration, test, documentation, and workflow files
  in this repository were newly authored for this project and are released
  under Apache-2.0.
- `LICENSE` is the unmodified Apache License 2.0 text distributed with Ubuntu.
- Source files checked by `ament_copyright` contain recognized Apache-2.0
  headers. `package.xml`, `setup.py`, and `CITATION.cff` all declare version
  0.1.0 and/or Apache-2.0 consistently.
- The committed PNG and JSON files were generated by the repository's own
  deterministic simulation. They contain no third-party robot asset, paper
  figure, participant material, or experimental log.

## Reference boundary

The local manuscript and both legacy controller implementations were used only
to verify equations, signs, and behavioral differences. Their source and prose
were not copied because an applicable repository-level redistribution license
was not established. Fingerprints and decisions are in
[`source-map.md`](source-map.md); the independent mathematical resolution is in
[`math_contract.md`](math_contract.md).

## Declared dependencies

Dependencies are resolved by ROS/Ubuntu or Python packaging and are not
vendored in this repository.

| Dependency | Use | Declared upstream/package license observed in the Humble environment |
|---|---|---|
| `rclpy`, `geometry_msgs`, `diagnostic_msgs`, `std_srvs` | ROS runtime/messages | Apache License 2.0 |
| `ament_index_python`, `launch`, `launch_ros` | package lookup and launch | Apache License 2.0 |
| NumPy | controller mathematics | BSD-style |
| Matplotlib | optional generated demo plot | PSF/BSD-compatible distribution terms |
| setuptools | build tooling | permissive; not bundled |
| pytest and ament linters | tests only | permissive; not bundled |

No dependency source or binary is redistributed in this repository. A binary
redistributor remains responsible for the notices of the exact dependency
versions it ships.

## Conclusion

No copied code of unclear provenance, copyleft source, private manuscript
content, or external media is included. The repository's first-party release
surface is consistently Apache-2.0. Re-run this audit whenever dependencies,
assets, generated data, or source provenance change.
